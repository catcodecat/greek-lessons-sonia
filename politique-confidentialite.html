Données personnelles

Politique de confidentialité

Cette page explique comment les données transmises via le site Sonia Line — cours particuliers de grec sont collectées, utilisées et conservées.

Données collectées

Le site peut collecter les données suivantes lorsque l'utilisateur remplit un formulaire :

  • nom ;
  • adresse email ;
  • demande de réservation de cours ;
  • message de contact.

Stockage des données

Les données envoyées via les formulaires sont enregistrées dans une base de données SQLite utilisée par le projet.

Finalités du traitement

Les données sont utilisées uniquement pour comprendre la demande de l'utilisateur, répondre à une demande de contact, organiser une demande de cours ou assurer le suivi administratif du projet.

Durée de conservation

Les données sont conservées pendant une durée maximale de 12 mois après le dernier échange, sauf demande de suppression anticipée ou obligation légale contraire.

Droits des utilisateurs

Conformément au RGPD, l'utilisateur peut demander l'accès à ses données, leur rectification ou leur suppression.

Contact pour exercer vos droits

Pour toute demande relative aux données personnelles, l'utilisateur peut contacter la responsable du site à l'adresse suivante : contact@sonialine-grec.example.

Cette adresse est un placeholder utilisé dans le cadre du projet de formation.

Sécurité

Le projet limite les données collectées aux informations nécessaires au traitement des demandes. Les accès à la base de données doivent rester réservés à l'administrateur du projet.
