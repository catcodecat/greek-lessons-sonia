# Explications pour l’examen

## 1. Analyse du brief client

Le client est Sonia Line, professeure de grec. Elle souhaite un site vitrine pour présenter ses cours particuliers, son parcours et sa passion pour la culture grecque. Le site doit donner confiance et donner envie de réserver un cours d’essai.

## 2. Identification des acteurs

J’ai identifié deux acteurs principaux. Le premier est le visiteur, qui consulte les pages et peut envoyer une demande de contact. Le deuxième est Sonia Line, administratrice du contenu, qui reçoit les demandes et peut faire modifier les textes du site.

## 3. Diagramme de cas d’utilisation

Le diagramme de cas d’utilisation présente les actions possibles : consulter l’accueil, découvrir Sonia Line, voir les cours, lire les avantages, envoyer une demande et consulter les coordonnées. Pour l’administrateur, les actions sont recevoir les demandes, modifier les informations et gérer les contenus.

## 4. Choix des pages et des blocs

Le site contient cinq pages. La page d’accueil présente l’offre principale avec les blocs essentiels : hero, à propos, pourquoi apprendre le grec, méthode, formats des cours, voyage dans la culture grecque, témoignages, FAQ et appel à l’action. La page À propos explique le parcours de Sonia Line. La page Cours détaille les formats proposés. La page Culture montre l’univers grec. La page Contact permet de faire une demande.

## 5. Design system

Le design suit le concept “Athènes classique et soleil doux”. Il utilise un bleu nuit d’Athènes, un ivoire antique, un or antique, un bleu mer Égée et un brun argile. Les titres utilisent une police serif élégante et le texte utilise une police sans-serif moderne.

## 6. Wireframes

Les wireframes sont décrits en version mobile et desktop. Sur mobile, les sections sont empilées et le menu est un burger. Sur desktop, la navigation est complète, le hero est en deux colonnes et les cartes sont affichées en grille.

## 7. Approche mobile first

J’ai choisi l’approche mobile first parce qu’elle permet de commencer par l’essentiel. Le site reste lisible sur petit écran, puis il devient plus riche sur tablette et desktop grâce aux media queries.

## 8. Développement HTML

Les pages HTML utilisent des balises sémantiques comme `header`, `nav`, `main`, `section`, `article`, `aside` et `footer`. Chaque page possède un titre différent, une hiérarchie de titres claire et une navigation fonctionnelle.

## 9. Développement CSS

Le CSS utilise des variables dans `:root`, Flexbox, Grid et des media queries. Les composants principaux sont le header, les boutons, les cartes, le hero, le formulaire et le footer.

## 10. Interactions JavaScript

Le JavaScript gère le menu burger, la fermeture du menu au clic sur un lien, la validation simple du formulaire et l’affichage d’un message de confirmation. Une animation légère au scroll est aussi ajoutée, ainsi qu’un comportement simple pour la FAQ.

## 11. Tests réalisés

Les tests prévus concernent l’affichage mobile, l’affichage desktop, la navigation, le menu burger, le formulaire vide, le formulaire rempli, les liens internes, la cohérence graphique, l’accessibilité de base et le responsive.

## 12. Conclusion du projet

Ce projet permet de transformer le besoin d’une professeure de grec en un site web structuré, responsive et cohérent visuellement. Le site met en valeur l’identité de Sonia Line, ses cours particuliers et son univers culturel inspiré de la Grèce.
