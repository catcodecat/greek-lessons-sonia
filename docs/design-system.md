# Design system

## Concept visuel

Le concept choisi est “Athènes classique et soleil doux”. Le site doit être élégant, lumineux, méditerranéen et légèrement académique. Il ne cherche pas une ambiance touristique trop plage, mais plutôt une atmosphère faite d’Athènes, de livres anciens, de mythologie, de mer Égée, de soleil doux et de transmission personnelle.

## Ambiance

Le design doit transmettre : sérieux, culture, chaleur, voyage, mythologie, confiance et élégance. L’idée principale est : “Je ne fais pas seulement de la grammaire, je découvre la culture grecque avec une personne qui la connaît vraiment.”

## Couleurs

- Bleu nuit d’Athènes : `#1E3A5F`, utilisé pour les titres, les boutons et les accents principaux.
- Ivoire antique : `#FAF3E6`, utilisé pour le fond général du site.
- Or antique : `#D6A84F`, utilisé pour les lignes décoratives, les détails et les CTA.
- Bleu mer Égée : `#4A90A4`, utilisé pour les liens, les hover effects et certains détails.
- Brun argile : `#9C6B4E`, utilisé pour les petits textes d’introduction, les séparateurs et l’ambiance terre cuite.

## Typographies

- Titres : `Cormorant Garamond`, serif élégant.
- Texte courant : `Inter`, sans-serif moderne et lisible.

Les polices sont chargées avec Google Fonts dans chaque page HTML.

## Composants

- Header fixe en haut avec logo et navigation.
- Menu burger sur mobile.
- Hero section avec texte fort et portrait de Sonia Line si la photo est ajoutée.
- Cartes pour les avantages et les cours.
- Témoignages.
- FAQ.
- Boutons principaux et secondaires.
- Formulaire de contact accessible avec labels.
- Footer en colonnes sur desktop.
- Titres de section réutilisables avec eyebrow.

## Boutons

### Bouton principal

- Fond bleu.
- Texte blanc.
- Utilisé pour les actions importantes, comme réserver un cours d’essai.

### Bouton secondaire

- Fond transparent.
- Bordure bleue.
- Texte bleu.
- Utilisé pour les actions de découverte.

## Responsive

Le CSS est écrit en mobile first. Les styles de base correspondent au mobile, puis des media queries ajoutent les grilles, les colonnes et la navigation desktop.
